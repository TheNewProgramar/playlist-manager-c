# 🎵 Playlist Manager

A simple playlist manager written in C using linked lists.

## ✨ Features

- ✅ Add songs to playlist
- ✅ Remove songs
- ✅ Play next song
- ✅ Display playlist
- ✅ Search for songs
- ✅ Dynamic size (linked list)

## 🛠️ Planned Features

- [ ] Shuffle playlist
- [ ] Save/Load playlist
- [ ] Repeat mode
- [ ] Sort playlist

## 🚀 How to Compile

```bash
gcc -Wall -Wextra -o playlist_manager main.c
```
## 🏃 How to Run
```bash
./playlist_manager
```
